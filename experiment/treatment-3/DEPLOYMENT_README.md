# AWS Deployment Guide - Quick Start

## Overview

This directory contains automated scripts to deploy, test, and cleanup the AWS infrastructure generated by the Kiro Serverless Migration Skills.

**Purpose:** Prove that the Skills generate working, functional infrastructure (not just syntactically valid templates).

## Prerequisites

1. **AWS Account** with appropriate permissions
2. **AWS CLI** configured with credentials
3. **PowerShell** (Windows) or Bash (Linux/Mac)

## Quick Start (3 Steps)

### Step 1: Configure AWS Credentials (5 minutes)

```powershell
# Go to AWS Console → IAM → Security credentials → Create access key
# Then run:
aws configure
# Enter: Access Key ID, Secret Access Key, region (us-east-1), format (json)
```

### Step 2: Deploy Infrastructure (1-2 hours)

**Option A: Full Deployment (with RDS Aurora - $10-20 cost for 1-2 hours)**
```powershell
.\deploy_infrastructure.ps1
```

**Option B: Partial Deployment (without RDS - $2-5 cost, mostly Free Tier)**
```powershell
.\deploy_infrastructure.ps1 -SkipRDS
```

**Option C: Dry Run (validate templates only, no deployment)**
```powershell
.\deploy_infrastructure.ps1 -DryRun
```

### Step 3: Test Deployment (15-30 minutes)

```powershell
.\test_deployment.ps1
```

### Step 4: Cleanup (IMPORTANT - 10 minutes)

**⚠️ Run this immediately after testing to avoid ongoing charges!**

```powershell
.\cleanup_infrastructure.ps1
```

## Deployment Phases

The deployment script executes in 5 phases:

1. **Phase 1: Network (VPC)** - 5-10 minutes
   - VPC with public/private subnets
   - NAT Gateway, Internet Gateway
   - Security Groups

2. **Phase 2: Database (RDS)** - 30-60 minutes *(optional, most expensive)*
   - Aurora Serverless v2 PostgreSQL
   - RDS Proxy for connection pooling
   - Cost: ~$88/month (~$0.12/hour)

3. **Phase 3: DynamoDB** - 5-10 minutes
   - Tables for NoSQL data
   - Cost: Free Tier eligible

4. **Phase 4: API Gateway + Lambda Authorizer** - 10-15 minutes
   - REST API Gateway
   - Lambda Authorizer function
   - Cost: Free Tier eligible

5. **Phase 5: S3 + Lambda Presigned URL** - 10-15 minutes
   - S3 bucket for file uploads
   - Lambda function for presigned URLs
   - Cost: Free Tier eligible

**Total Time:** 60-110 minutes (depending on RDS)  
**Total Cost:** 
- Full deployment: ~$10-20 for 1-2 hours
- Without RDS: ~$2-5 (mostly Free Tier)

## Testing

The test script validates:

1. ✅ VPC and networking infrastructure exists
2. ✅ RDS Aurora database is available (if deployed)
3. ✅ DynamoDB tables are active
4. ✅ API Gateway is accessible
5. ✅ Lambda functions are active and invokable
6. ✅ S3 bucket accepts uploads and downloads

**Evidence Generated:**
- `test_results/test_results.json` - Structured test results
- `test_results/test_log_*.txt` - Detailed test execution log
- Screenshots from AWS Console (manual)

## Cleanup

The cleanup script:

1. Empties S3 buckets (required before deletion)
2. Deletes CloudFormation stacks in reverse order
3. Verifies all resources are deleted
4. Reports any remaining resources

**Safety:** Requires typing "DELETE" to confirm (unless `-Force` flag used).

## Troubleshooting

### AWS CLI Not Configured
```powershell
# Error: "You must specify a region"
# Solution: Run aws configure
aws configure
```

### Stack Creation Failed
```powershell
# View stack events to see error
aws cloudformation describe-stack-events --stack-name kiro-migration-vpc --region us-east-1
```

### S3 Bucket Deletion Failed
```powershell
# Bucket must be empty before deletion
aws s3 rm s3://YOUR-BUCKET-NAME --recursive --region us-east-1
```

### RDS Taking Too Long
```powershell
# RDS Aurora can take 30-60 minutes to provision
# Check status:
aws rds describe-db-clusters --db-cluster-identifier YOUR-CLUSTER-ID --region us-east-1
```

### Cleanup Failed
```powershell
# If cleanup script fails, manually delete stacks in AWS Console
# Go to CloudFormation → Select stack → Delete
# Order: presigned-lambda → s3 → api-gateway → authorizer → rds → vpc
```
